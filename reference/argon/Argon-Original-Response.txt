```markdown
## 2. CAPACIDADES REALES Y LIMITACIONES FÍSICAS DE INTEL UHD + MEMORIA COMPARTIDA

### A. El Cuello de Botella del Ancho de Banda Compartido (UMA Contention)
En una PC con GPU dedicada, la CPU usa la RAM DDR4/DDR5 (~20–50 GB/s) y la GPU usa su propia VRAM GDDR6 (~250–500 GB/s). En tu equipo con **Intel UHD y memoria compartida**, **tanto los núcleos de la CPU como las Unidades de Ejecución (EUs) de la Intel UHD compiten simultáneamente por el mismo controlador de memoria y los mismos módulos RAM**.
* **Consecuencia en CS2:** Cada vez que el Administrador de Ventanas de Escritorio (DWM), un navegador, Discord con aceleración por hardware o la superposición de Steam leen/escriben en RAM, le roban ancho de banda directo al renderizado de CS2, provocando caídas abruptas en los **1% lows y 0.1% lows**.

### B. El Error Fatal de los Optimizadores Genéricos: Presupuesto Térmico y Eléctrico Compartido (PL1/PL2)
Los optimizadores convencionales fuerzan planes de energía que bloquean la CPU al 100% de frecuencia máxima constante.
* **Por qué eso perjudica a tu PC:** En un procesador Intel con gráficos UHD, el paquete tiene un límite de energía total (PL1/PL2) y un único disipador térmico. Si obligas a los núcleos de la CPU a consumir el máximo voltaje y frecuencia en todo momento, **la CPU acapara el presupuesto de energía (Package Power) y provoca Power Throttling en la iGPU Intel UHD**, haciendo que la frecuencia gráfica caiga de ~1050-1200 MHz a 400-600 MHz.
* **Enfoque de EVO FPS OPTIMIZER:** En hardware Intel UHD, debemos equilibrar el **EPP (Energy Performance Preference)** para que la CPU procese la lógica del juego sin estrangular el presupuesto eléctrico que necesita el motor gráfico integrado (GT).

### C. Presión de Memoria Comprometida (Commit Charge) y Paginación
CS2 en Source 2 consume entre 2.5 GB y 4.5 GB de RAM del sistema más 1.5 GB a 3.0 GB de buffers gráficos que, al no existir VRAM dedicada, **también se alojan en tu RAM física**.
* Si Windows tiene procesos en segundo plano innecesarios, la memoria comprometida supera la RAM física libre y el kernel empieza a paginar texturas de la iGPU hacia el disco SSD/HDD, generando *stuttering* severo (congelamientos de 50 ms a 300 ms al asomarse a un ángulo o ver una granada de humo).

## 3. RIESGOS Y FALSAS OPTIMIZACIONES QUE EVO PROHÍBE EN TU EQUIPO

1. **PROHIBIDO desactivar el Archivo de Paginación (Memoria Virtual):** En sistemas con memoria compartida UMA, desactivar el archivo de paginación provoca cierres inmediatos de CS2 (`Out of Video Memory` / `Allocation Failed`) porque DirectX 11 asigna memoria virtual comprometida para respaldar las superficies compartidas.
2. **PROHIBIDO usar trucos de BCD (`useplatformclock`, `disabledynamictick`):** En procesadores Intel modernos reducen el rendimiento single-core y aumentan la latencia de llamada al sistema del kernel.
3. **PROHIBIDO forzar prioridad "Tiempo Real" (`Realtime`) a `cs2.exe`:** Provoca que los hilos del juego compitan e inanición (starvation) contra el hilo del controlador de pantalla de Intel (`igdkmdn64.sys`) y el subproceso de entrada del mouse/teclado (`csrss.exe`).
4. **PROHIBIDO aplicar scripts genéricos que desactiven Windows Defender, Firewall o servicios críticos de red/audio.**

---

## 4. OPORTUNIDADES DE OPTIMIZACIÓN VERIFICABLES PARA ESTA ARQUITECTURA

1. **Liberación de Ancho de Banda UMA:**
   * Desactivar Xbox Game Bar, GameDVR y capturas en segundo plano (elimina un buffer de codificación continua en la iGPU Intel QuickSync/UHD).
   * Desactivar aceleración por hardware en clientes secundarios (Steam WebHelper, Discord) para que no reserven segmentos de memoria compartida ni compitan por las Unidades de Ejecución 3D de la Intel UHD.
   * Reducir efectos de transparencia y composición innecesaria de Windows DWM.
2. **Optimización de Memoria y Paginación:**
   * Auditoría y poda autorizada de aplicaciones de inicio y procesos en segundo plano antes de iniciar CS2 para maximizar la RAM física contigua disponible para la UMA.
3. **Afinación Específica de CS2 (`cs2_video.txt`):**
   * Las granadas de humo volumétricas de Source 2 y las sombras dinámicas saturan el *fillrate* de Intel UHD. Configurar `setting.shaderquality = 0`, `setting.particle_detail = 0`, `setting.msaa_samples = 0` (el MSAA multiplica exponencialmente el consumo de ancho de banda de RAM compartida), y usar **FidelityFX Super Resolution (FSR) en modo Balanced/Performance** solo si la visibilidad competitiva se mantiene aceptable en resoluciones 4:3 estiradas (`1024x768` o `1280x960`).

---

## 5. FUNCIONES INCOMPATIBLES CON INTEL UHD (BLOQUEADAS POR EVO)
* **NVIDIA Reflex / NVIDIA Low Latency Mode / AMD Anti-Lag:** Incompatibles (Hardware Intel).
* **Resizable BAR / Dedicated VRAM Overclocking:** No aplicable a memoria UMA estándar sin soporte específico de placa.
* **HAGS (Hardware Accelerated GPU Scheduling):** En muchos controladores Intel UHD de generaciones anteriores, HAGS introduce micro-stuttering bajo presión de memoria compartida; EVO lo audita y mide con PresentMon antes de recomendar activarlo.
```

```csharp
    public class EvoDatabase
    {
        public string BaseWorkspaceDirectory { get; }
        public string BackupsDirectory { get; }
        public string ScriptsDirectory { get; }
        public string ReportsDirectory { get; }
        private readonly string _connectionString;

        public EvoDatabase()
        {
            BaseWorkspaceDirectory = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData),
                "EvoFpsOptimizer");

            BackupsDirectory = Path.Combine(BaseWorkspaceDirectory, "Backups");
            ScriptsDirectory = Path.Combine(BaseWorkspaceDirectory, "Scripts");
            ReportsDirectory = Path.Combine(BaseWorkspaceDirectory, "Reports");

            Directory.CreateDirectory(BaseWorkspaceDirectory);
            Directory.CreateDirectory(BackupsDirectory);
            Directory.CreateDirectory(ScriptsDirectory);
            Directory.CreateDirectory(ReportsDirectory);

            string dbPath = Path.Combine(BaseWorkspaceDirectory, "evo_telemetry.db");
            _connectionString = $"Data Source={dbPath}";
            InitializeSchema();
        }

        private void InitializeSchema()
        {
            using var conn = new SqliteConnection(_connectionString);
            conn.Open();

            using var cmd = conn.CreateCommand();
            cmd.CommandText = @"
                CREATE TABLE IF NOT EXISTS Audits (
                    AuditId TEXT PRIMARY KEY,
                    Timestamp TEXT NOT NULL,
                    JsonPayload TEXT NOT NULL
                );

                CREATE TABLE IF NOT EXISTS OptimizationTransactions (
                    Id INTEGER PRIMARY KEY AUTOINCREMENT,
                    RuleId TEXT NOT NULL,
                    RuleName TEXT NOT NULL,
                    AppliedAt TEXT NOT NULL,
                    PreviousValue TEXT,
                    NewValue TEXT,
                    BackupRegFilePath TEXT,
                    ApplyRegFilePath TEXT,
                    RevertRegFilePath TEXT,
                    ExecutedPowerShellPath TEXT,
                    IsVerified INTEGER NOT NULL,
                    IsReverted INTEGER NOT NULL DEFAULT 0
                );

                CREATE TABLE IF NOT EXISTS Benchmarks (
                    BenchmarkId TEXT PRIMARY KEY,
                    Timestamp TEXT NOT NULL,
                    Label TEXT NOT NULL,
                    JsonPayload TEXT NOT NULL
                );
            ";
            cmd.ExecuteNonQuery();
        }

        public void SaveAudit(SystemAuditReport report)
        {
            string json = JsonSerializer.Serialize(report, new JsonSerializerOptions { WriteIndented = true });
            using var conn = new SqliteConnection(_connectionString);
            conn.Open();
            using var cmd = conn.CreateCommand();
            cmd.CommandText = "INSERT OR REPLACE INTO Audits (AuditId, Timestamp, JsonPayload) VALUES ($id, $ts, $json)";
            cmd.Parameters.AddWithValue("$id", report.AuditId);
            cmd.Parameters.AddWithValue("$ts", report.Timestamp.ToString("O"));
            cmd.Parameters.AddWithValue("$json", json);
            cmd.ExecuteNonQuery();
        }

        public List<SystemAuditReport> GetRecentAudits(int limit = 10)
        {
            var list = new List<SystemAuditReport>();
            using var conn = new SqliteConnection(_connectionString);
            conn.Open();
            using var cmd = conn.CreateCommand();
            cmd.CommandText = "SELECT JsonPayload FROM Audits ORDER BY Timestamp DESC LIMIT $limit";
            cmd.Parameters.AddWithValue("$limit", limit);
            using var reader = cmd.ExecuteReader();
            while (reader.Read())
            {
                var report = JsonSerializer.Deserialize<SystemAuditReport>(reader.GetString(0));
                if (report != null) list.Add(report);
            }
            return list;
        }

        public long SaveTransaction(OptimizationTransactionRecord tx)
        {
            using var conn = new SqliteConnection(_connectionString);
            conn.Open();
            using var cmd = conn.CreateCommand();
            cmd.CommandText = @"
                INSERT INTO OptimizationTransactions 
                (RuleId, RuleName, AppliedAt, PreviousValue, NewValue, BackupRegFilePath, ApplyRegFilePath, RevertRegFilePath, ExecutedPowerShellPath, IsVerified, IsReverted)
                VALUES ($rid, $rname, $at, $prev, $new, $breg, $areg, $rreg, $ps, $ver, $rev);
                SELECT last_insert_rowid();";
            cmd.Parameters.AddWithValue("$rid", tx.RuleId);
            cmd.Parameters.AddWithValue("$rname", tx.RuleName);
            cmd.Parameters.AddWithValue("$at", tx.AppliedAt.ToString("O"));
            cmd.Parameters.AddWithValue("$prev", tx.PreviousValue);
            cmd.Parameters.AddWithValue("$new", tx.NewValue);
            cmd.Parameters.AddWithValue("$breg", tx.BackupRegFilePath);
            cmd.Parameters.AddWithValue("$areg", tx.ApplyRegFilePath);
            cmd.Parameters.AddWithValue("$rreg", tx.RevertRegFilePath);
            cmd.Parameters.AddWithValue("$ps", tx.ExecutedPowerShellPath);
            cmd.Parameters.AddWithValue("$ver", tx.IsVerified ? 1 : 0);
            cmd.Parameters.AddWithValue("$rev", tx.IsReverted ? 1 : 0);
            return (long)(cmd.ExecuteScalar() ?? 0L);
        }

        public void MarkTransactionReverted(long id)
        {
            using var conn = new SqliteConnection(_connectionString);
            conn.Open();
            using var cmd = conn.CreateCommand();
            cmd.CommandText = "UPDATE OptimizationTransactions SET IsReverted = 1 WHERE Id = $id";
            cmd.Parameters.AddWithValue("$id", id);
            cmd.ExecuteNonQuery();
        }

        public List<OptimizationTransactionRecord> GetAllTransactions()
        {
            var list = new List<OptimizationTransactionRecord>();
            using var conn = new SqliteConnection(_connectionString);
            conn.Open();
            using var cmd = conn.CreateCommand();
            cmd.CommandText = "SELECT Id, RuleId, RuleName, AppliedAt, PreviousValue, NewValue, BackupRegFilePath, ApplyRegFilePath, RevertRegFilePath, ExecutedPowerShellPath, IsVerified, IsReverted FROM OptimizationTransactions ORDER BY Id DESC";
            using var reader = cmd.ExecuteReader();
            while (reader.Read())
            {
                list.Add(new OptimizationTransactionRecord
                {
                    Id = reader.GetInt64(0),
                    RuleId = reader.GetString(1),
                    RuleName = reader.GetString(2),
                    AppliedAt = DateTime.Parse(reader.GetString(3)),
                    PreviousValue = reader.GetString(4),
                    NewValue = reader.GetString(5),
                    BackupRegFilePath = reader.GetString(6),
                    ApplyRegFilePath = reader.GetString(7),
                    RevertRegFilePath = reader.GetString(8),
                    ExecutedPowerShellPath = reader.GetString(9),
                    IsVerified = reader.GetInt32(10) == 1,
                    IsReverted = reader.GetInt32(11) == 1
                });
            }
            return list;
        }

        public void SaveBenchmark(BenchmarkResult bench)
        {
            string json = JsonSerializer.Serialize(bench, new JsonSerializerOptions { WriteIndented = true });
            using var conn = new SqliteConnection(_connectionString);
            conn.Open();

            cmd.CommandText = "INSERT OR REPLACE INTO Benchmarks (BenchmarkId, Timestamp, Label, JsonPayload) VALUES ($id, $ts, $lbl, $json)";

            cmd.Parameters.AddWithValue("$ts", bench.Timestamp.ToString("O"));
            cmd.Parameters.AddWithValue("$lbl", bench.Label);
            cmd.Parameters.AddWithValue("$json", json);
```

## 3. EVO SYSTEM AUDITOR — Auditoría Completa y Diff Engine: `src/EvoFpsOptimizer/Services/EvoSystemAuditor.cs`

*(Inspecciona hardware real vía WMI/CIM, detecta si la GPU es UMA compartida, audita RAM Single vs Dual Channel, busca instalación de Steam/CS2, exporta TXT/JSON/HTML y compara 2 auditorías).*

```csharp
using System;
using System.Collections.Generic;
using System.Diagnostics;
using System.IO;
using System.Linq;
using System.Management;
using System.Net.NetworkInformation;
using System.ServiceProcess;
using System.Text;
using System.Text.Json;
using EvoFpsOptimizer.Data;
using EvoFpsOptimizer.Models;
using Microsoft.Win32;

namespace EvoFpsOptimizer.Services
{
    public class EvoSystemAuditor
    {
        private readonly EvoDatabase _db;

        private static readonly HashSet<string> ProtectedServices = new(StringComparer.OrdinalIgnoreCase)
        {
            "WinDefend", "WdNisSvc", "mpssvc", "BFE", "wuauserv", "Dhcp", "Dnscache",
            "Audiosrv", "AudioEndpointBuilder", "RpcSs", "DcomLaunch", "LSM", "SamSs", "EventLog", "Steam Client Service"
        };

        private static readonly HashSet<string> ProtectedProcesses = new(StringComparer.OrdinalIgnoreCase)
        {
            "System", "Registry", "smss", "csrss", "wininit", "services", "lsass", "svchost",
            "winlogon", "dwm", "explorer", "MsMpEng", "SecurityHealthService", "audiodg"
        };

        public EvoSystemAuditor(EvoDatabase db)
        {
            _db = db;
        }

        public SystemAuditReport RunFullSystemAudit()
        {
            var report = new SystemAuditReport
            {
                Timestamp = DateTime.Now
            };

            AuditComputerAndMotherboard(report);
            AuditCpuAndThermal(report);
            AuditGpuAndUmaArchitecture(report);
            AuditMemoryAndCommitCharge(report);
            AuditStorage(report);
            AuditWindowsAndSecurity(report);
            AuditNetwork(report);
            AuditSteamAndCs2(report);
            AuditProcessesServicesAndDrivers(report);

            _db.SaveAudit(report);
            return report;
        }

        private void AuditComputerAndMotherboard(SystemAuditReport report)
        {
            try
            {
                using var csSearcher = new ManagementObjectSearcher("SELECT Manufacturer, Model, TotalPhysicalMemory FROM Win32_ComputerSystem");
                foreach (ManagementObject obj in csSearcher.Get())
                {
                    report.ComputerManufacturer = obj["Manufacturer"]?.ToString()?.Trim() ?? "DESCONOCIDO";
                    report.ComputerModel = obj["Model"]?.ToString()?.Trim() ?? "DESCONOCIDO";
                    if (ulong.TryParse(obj["TotalPhysicalMemory"]?.ToString(), out ulong totalRam))
                        report.TotalPhysicalRamBytes = (long)totalRam;
                }

                using var bbSearcher = new ManagementObjectSearcher("SELECT Manufacturer, Product FROM Win32_BaseBoard");
                foreach (ManagementObject obj in bbSearcher.Get())
                {
                    report.Motherboard = $"{obj["Manufacturer"]} {obj["Product"]}".Trim();
                }

                using var biosSearcher = new ManagementObjectSearcher("SELECT SMBIOSBIOSVersion, ReleaseDate FROM Win32_BIOS");
                foreach (ManagementObject obj in biosSearcher.Get())
                {
                    report.BiosVersion = $"{obj["SMBIOSBIOSVersion"]} ({obj["ReleaseDate"]})".Trim();
                }
            }
            catch { /* Manejo seguro si WMI está restringido */ }
        }

        private void AuditCpuAndThermal(SystemAuditReport report)
        {
            try
            {
                using var cpuSearcher = new ManagementObjectSearcher("SELECT Name, NumberOfCores, NumberOfLogicalProcessors, MaxClockSpeed, CurrentClockSpeed FROM Win32_Processor");
                foreach (ManagementObject obj in cpuSearcher.Get())
                {
                    report.CpuName = obj["Name"]?.ToString()?.Trim() ?? "DESCONOCIDO";
                    report.PhysicalCores = Convert.ToInt32(obj["NumberOfCores"] ?? 0);
                    report.LogicalProcessors = Convert.ToInt32(obj["NumberOfLogicalProcessors"] ?? 0);
                    report.BaseClockMhz = Convert.ToInt32(obj["MaxClockSpeed"] ?? 0);
                    report.CurrentClockMhz = Convert.ToInt32(obj["CurrentClockSpeed"] ?? 0);
                }

                // Intentar leer zona térmica ACPI real (no inventar temperatura si no existe)
                using var tempSearcher = new ManagementObjectSearcher(@"root\WMI", "SELECT CurrentTemperature FROM MSAcpi_ThermalZoneTemperature");
                foreach (ManagementObject obj in tempSearcher.Get())
                {
                    double kelvinTenths = Convert.ToDouble(obj["CurrentTemperature"] ?? 0);
                    if (kelvinTenths > 2732)
                    {
                        double celsius = (kelvinTenths / 10.0) - 273.15;
                        if (celsius > 10 && celsius < 115)
                            report.CpuTemperatureCelsius = Math.Round(celsius, 1);
                    }
                }
            }
            catch
            {
                report.CpuTemperatureCelsius = null; // Etiquetado explícito: No verificable sin sensor
            }
        }

        private void AuditGpuAndUmaArchitecture(SystemAuditReport report)
        {
            try
            {
                using var gpuSearcher = new ManagementObjectSearcher("SELECT Name, DriverVersion, DriverDate, AdapterRAM, CurrentHorizontalResolution, CurrentVerticalResolution, CurrentRefreshRate FROM Win32_VideoController");
                foreach (ManagementObject obj in gpuSearcher.Get())
                {
                    string name = obj["Name"]?.ToString()?.Trim() ?? "DESCONOCIDO";
                    report.GpuName = name;
                    report.GpuDriverVersion = obj["DriverVersion"]?.ToString() ?? "DESCONOCIDO";
                    report.GpuDriverDate = obj["DriverDate"]?.ToString() ?? "DESCONOCIDO";

                    long adapterRam = Convert.ToInt64(obj["AdapterRAM"] ?? 0L);
                    bool isIntelIntegrated = name.Contains("Intel", StringComparison.OrdinalIgnoreCase) &&
                                             (name.Contains("UHD", StringComparison.OrdinalIgnoreCase) ||
                                              name.Contains("HD Graphics", StringComparison.OrdinalIgnoreCase) ||
                                              name.Contains("Iris", StringComparison.OrdinalIgnoreCase));

                    report.IsIntegratedUma = isIntelIntegrated;
                    report.PreAllocatedDvmtBytes = adapterRam;
                    // En Windows, la memoria compartida máxima para iGPU es 50% de la RAM física total
                    report.SharedSystemMemoryBytes = report.TotalPhysicalRamBytes / 2;

                    int hRes = Convert.ToInt32(obj["CurrentHorizontalResolution"] ?? 0);
                    int vRes = Convert.ToInt32(obj["CurrentVerticalResolution"] ?? 0);
                    if (hRes > 0 && vRes > 0)
                        report.DisplayResolution = $"{hRes}x{vRes}";
                    report.DisplayRefreshRateHz = Convert.ToInt32(obj["CurrentRefreshRate"] ?? 60);
                }
            }
            catch { }
        }

        private void AuditMemoryAndCommitCharge(SystemAuditReport report)
        {
            try
            {
                using var memSearcher = new ManagementObjectSearcher("SELECT BankLabel, Manufacturer, PartNumber, Capacity, Speed, ConfiguredClockSpeed FROM Win32_PhysicalMemory");
                foreach (ManagementObject obj in memSearcher.Get())
                {
                    var stick = new RamStickInfo
                    {
                        BankLabel = obj["BankLabel"]?.ToString()?.Trim() ?? "Slot",
                        Manufacturer = obj["Manufacturer"]?.ToString()?.Trim() ?? "Genérico",
                        PartNumber = obj["PartNumber"]?.ToString()?.Trim() ?? "N/A",
                        CapacityBytes = Convert.ToInt64(obj["Capacity"] ?? 0L),
                        NominalSpeedMhz = Convert.ToInt32(obj["Speed"] ?? 0),
                        ConfiguredSpeedMhz = Convert.ToInt32(obj["ConfiguredClockSpeed"] ?? obj["Speed"] ?? 0)
                    };
                    report.RamModules.Add(stick);
                }

                report.RamModuleCount = report.RamModules.Count;
                report.ConfiguredRamSpeedMhz = report.RamModules.FirstOrDefault()?.ConfiguredSpeedMhz ?? 0;
                report.RamChannelMode = report.RamModuleCount >= 2 ? "Dual-Channel (Inferido por múltiples módulos)" :
                                        report.RamModuleCount == 1 ? "Single-Channel (1 solo módulo detectado - Limitación severa para UMA)" : "DESCONOCIDO";

                using var osSearcher = new ManagementObjectSearcher("SELECT FreePhysicalMemory, TotalVirtualMemorySize, FreeVirtualMemory FROM Win32_OperatingSystem");
                foreach (ManagementObject obj in osSearcher.Get())
                {
                    long freePhysKb = Convert.ToInt64(obj["FreePhysicalMemory"] ?? 0L);
                    long totalVirtKb = Convert.ToInt64(obj["TotalVirtualMemorySize"] ?? 0L);
                    long freeVirtKb = Convert.ToInt64(obj["FreeVirtualMemory"] ?? 0L);

                    report.AvailablePhysicalRamBytes = freePhysKb * 1024L;
                    report.CommitLimitBytes = totalVirtKb * 1024L;
                    report.CommittedBytes = (totalVirtKb - freeVirtKb) * 1024L;
                }
            }
            catch { }
        }

        private void AuditStorage(SystemAuditReport report)
        {
            try
            {
                foreach (var drive in DriveInfo.GetDrives().Where(d => d.IsReady && d.DriveType == DriveType.Fixed))
                {
                    report.Disks.Add(new DiskAuditInfo
                    {
                        DriveLetter = drive.Name,
                        Model = drive.VolumeLabel,
                        MediaType = "Fixed Storage",
                        HealthStatus = "Operativo",
                        TotalSizeBytes = drive.TotalSize,
                        FreeSpaceBytes = drive.AvailableFreeSpace
                    });
                }
            }
            catch { }
        }

        private void AuditWindowsAndSecurity(SystemAuditReport report)
        {
            try
            {
                using var osSearcher = new ManagementObjectSearcher("SELECT Caption, Version, BuildNumber FROM Win32_OperatingSystem");
                foreach (ManagementObject obj in osSearcher.Get())
                {
                    report.OsCaption = obj["Caption"]?.ToString()?.Trim() ?? "Windows";
                    report.OsVersion = obj["Version"]?.ToString() ?? "";
                    report.OsBuild = obj["BuildNumber"]?.ToString() ?? "";
                }

                // Game Mode
                using var gmKey = Registry.CurrentUser.OpenSubKey(@"Software\Microsoft\GameBar");
                if (gmKey != null)
                {
                    int autoGm = Convert.ToInt32(gmKey.GetValue("AutoGameModeEnabled", 1));
                    report.GameModeEnabled = autoGm == 1;
                }

                // Game DVR / Capturas en segundo plano
                using var dvrKey = Registry.CurrentUser.OpenSubKey(@"Software\Microsoft\Windows\CurrentVersion\GameDVR");
                if (dvrKey != null)
                {
                    int appCapture = Convert.ToInt32(dvrKey.GetValue("AppCaptureEnabled", 1));
                    report.GameDvrEnabled = appCapture == 1;
                }

                // HAGS
                using var gfxKey = Registry.LocalMachine.OpenSubKey(@"SYSTEM\CurrentControlSet\Control\GraphicsDrivers");
                if (gfxKey != null)
                {
                    int hwSch = Convert.ToInt32(gfxKey.GetValue("HwSchMode", 1));
                    report.HagsEnabled = hwSch == 2;
                }

                // Windows Defender Service check
                var defenderSvc = ServiceController.GetServices().FirstOrDefault(s => s.ServiceName.Equals("WinDefend", StringComparison.OrdinalIgnoreCase));
                report.DefenderActive = defenderSvc?.Status == ServiceControllerStatus.Running;
            }
            catch { }
        }

        private void AuditNetwork(SystemAuditReport report)
        {
            try
            {
                var activeNic = NetworkInterface.GetAllNetworkInterfaces()
                    .FirstOrDefault(n => n.OperationalStatus == OperationalStatus.Up &&
                                         n.NetworkInterfaceType != NetworkInterfaceType.Loopback);
                if (activeNic != null)
                {
                    report.ActiveNetworkAdapter = $"{activeNic.Name} ({activeNic.Description})";
                    report.LinkSpeedMbps = activeNic.Speed / 1_000_000;
                }
            }
            catch { }
        }

        private void AuditSteamAndCs2(SystemAuditReport report)
        {
            try
            {
                using var steamKey = Registry.CurrentUser.OpenSubKey(@"Software\Valve\Steam");
                string? steamPath = steamKey?.GetValue("SteamPath")?.ToString()?.Replace("/", "\\");
                if (!string.IsNullOrEmpty(steamPath) && Directory.Exists(steamPath))
                {
                    report.SteamPath = steamPath;

                    // Buscar CS2 en libraryfolders o ruta por defecto
                    string defaultCs2 = Path.Combine(steamPath, @"steamapps\common\Counter-Strike Global Offensive\game\bin\win64\cs2.exe");
                    if (File.Exists(defaultCs2))
                    {
                        report.Cs2Path = defaultCs2;
                    }

                    // Buscar archivo cs2_video.txt en userdata
                    string userdataDir = Path.Combine(steamPath, "userdata");
                    if (Directory.Exists(userdataDir))
                    {
                        var videoFiles = Directory.GetFiles(userdataDir, "cs2_video.txt", SearchOption.AllDirectories);
                        if (videoFiles.Length > 0)
                        {
                            report.Cs2VideoConfigPath = videoFiles[0];
                        }
                    }
                }
            }
            catch { }
        }

        private void AuditProcessesServicesAndDrivers(SystemAuditReport report)
        {
            try
            {
                var procs = Process.GetProcesses()
                    .OrderByDescending(p =>
                    {
                        try { return p.WorkingSet64; } catch { return 0L; }
                    })
                    .Take(20);

                foreach (var p in procs)
                {
                    try
                    {
                        bool isProtected = ProtectedProcesses.Contains(p.ProcessName);
                        double mb = Math.Round(p.WorkingSet64 / (1024.0 * 1024.0), 1);
                        report.TopProcesses.Add(new ProcessDiagnosticItem
                        {
                            Pid = p.Id,
                            Name = p.ProcessName,
                            WorkingSetMb = mb,
                            IsProtectedSystemProcess = isProtected,
                            GamingImpactAssessment = isProtected
                                ? "Crítico del Sistema (Protegido por EVO)"
                                : mb > 300 ? "Alto consumo de RAM física (Reduce pool UMA disponible)" : "Impacto moderado/bajo"
                        });
                    }
                    catch { }
                }

                foreach (var svc in ServiceController.GetServices().Take(40))
                {
                    bool isCritical = ProtectedServices.Contains(svc.ServiceName);
                    report.RelevantServices.Add(new ServiceDiagnosticItem
                    {
                        ServiceName = svc.ServiceName,
                        DisplayName = svc.DisplayName,
                        Status = svc.Status.ToString(),
                        StartType = svc.StartType.ToString(),
                        IsProtectedCritical = isCritical,
                        Recommendation = isCritical ? "PROTEGIDO (Nunca desactivar)" : "Inspeccionable bajo demanda"
                    });
                }

                // Drivers con error
                using var drvSearcher = new ManagementObjectSearcher("SELECT Name, Manufacturer, ConfigManagerErrorCode FROM Win32_PnPEntity WHERE ConfigManagerErrorCode <> 0");
                foreach (ManagementObject obj in drvSearcher.Get())
                {
                    int errCode = Convert.ToInt32(obj["ConfigManagerErrorCode"] ?? 0);
                    report.ProblematicDrivers.Add(new DriverDiagnosticItem
                    {
                        DeviceName = obj["Name"]?.ToString() ?? "Dispositivo desconocido",
                        Manufacturer = obj["Manufacturer"]?.ToString() ?? "N/A",
                        ConfigManagerErrorCode = errCode,
                        StatusDescription = $"Error de dispositivo PnP Código {errCode}"
                    });
                }
            }
            catch { }
        }

        public string ExportReportToTxt(SystemAuditReport r)
        {
            var sb = new StringBuilder();

            sb.AppendLine("================================================================================");
            sb.AppendLine($"[EQUIPO]      {r.ComputerManufacturer} - {r.ComputerModel} [DETECTADO]");

            sb.AppendLine($"[SISTEMA OP]  {r.OsCaption} (Versión {r.OsVersion}, Build {r.OsBuild}) [DETECTADO]");

            sb.AppendLine($"[TEMPERATURA] {(r.CpuTemperatureCelsius.HasValue ? $"{r.CpuTemperatureCelsius.Value} °C [DETECTADO]" : "DESCONOCIDO (Sin sensor WMI expuesto)")}");
            sb.AppendLine($"[GRÁFICOS]    {r.GpuName} | Driver: {r.GpuDriverVersion} [DETECTADO]");
            sb.AppendLine($"[ARQ. VIDEO]  {(r.IsIntegratedUma ? "UMA Memoria Compartida (Intel Integrada)" : "GPU Dedicada")} | DVMT: {r.PreAllocatedDvmtBytes / (1024 * 1024)} MB | Compartida Máx: {r.SharedSystemMemoryBytes / (1024 * 1024)} MB [CALCULADO]");
            sb.AppendLine($"[MEMORIA RAM] Total: {r.TotalPhysicalRamBytes / (1024 * 1024)} MB | Libre: {r.AvailablePhysicalRamBytes / (1024 * 1024)} MB | Comprometida: {r.CommittedBytes / (1024 * 1024)} / {r.CommitLimitBytes / (1024 * 1024)} MB [DETECTADO]");
            sb.AppendLine($"[CANALES RAM] Módulos: {r.RamModuleCount} | Velocidad: {r.ConfiguredRamSpeedMhz} MHz | Modo: {r.RamChannelMode}");
            sb.AppendLine($"[WINDOWS]     GameMode: {r.GameModeEnabled} | GameDVR: {r.GameDvrEnabled} | HAGS: {r.HagsEnabled} | Defender Activo: {r.DefenderActive}");
            sb.AppendLine($"[CS2 / STEAM] Steam: {r.SteamPath} | CS2 Config: {r.Cs2VideoConfigPath}");
            sb.AppendLine("--------------------------------------------------------------------------------");
            sb.AppendLine("TOP PROCESOS POR CONSUMO DE MEMORIA FÍSICA:");
            foreach (var p in r.TopProcesses.Take(10))
            {
                sb.AppendLine($" - {p.Name} (PID {p.Pid}): {p.WorkingSetMb} MB -> {p.GamingImpactAssessment}");
            }

            string filePath = Path.Combine(_db.ReportsDirectory, $"EVO_Audit_{r.Timestamp:yyyyMMdd_HHmmss}.txt");
            File.WriteAllText(filePath, sb.ToString(), Encoding.UTF8);
            return filePath;
        }

        /// <summary>
        /// Módulo H: EVO CONFIGURATION DIFF — Compara dos auditorías reales y muestra qué cambió exactamente.
        /// </summary>
        public string CompareAudits(SystemAuditReport older, SystemAuditReport newer)
        {
            var sb = new StringBuilder();
            sb.AppendLine($"=== COMPARACIÓN DE AUDITORÍAS (EVO CONFIGURATION DIFF) ===");
            sb.AppendLine($"Anterior: {older.Timestamp:yyyy-MM-dd HH:mm:ss} ({older.AuditId})");
            sb.AppendLine($"Actual:   {newer.Timestamp:yyyy-MM-dd HH:mm:ss} ({newer.AuditId})");
            sb.AppendLine("----------------------------------------------------------");

            long ramDiffMb = (newer.AvailablePhysicalRamBytes - older.AvailablePhysicalRamBytes) / (1024 * 1024);

            sb.AppendLine($"• RAM Física Disponible: {older.AvailablePhysicalRamBytes / (1024 * 1024)} MB -> {newer.AvailablePhysicalRamBytes / (1024 * 1024)} MB (Diferencia: {(ramDiffMb >= 0 ? "+" : "")}{ramDiffMb} MB)");
            sb.AppendLine($"• Memoria Comprometida:  {older.CommittedBytes / (1024 * 1024)} MB -> {newer.CommittedBytes / (1024 * 1024)} MB (Diferencia: {(commitDiffMb >= 0 ? "+" : "")}{commitDiffMb} MB)");

            if (older.GameDvrEnabled != newer.GameDvrEnabled)
                sb.AppendLine($"• Cambio detectado en GameDVR (Capturas en segundo plano): {older.GameDvrEnabled} -> {newer.GameDvrEnabled}");

            if (older.GameModeEnabled != newer.GameModeEnabled)
                sb.AppendLine($"• Cambio detectado en Windows Game Mode: {older.GameModeEnabled} -> {newer.GameModeEnabled}");

            if (older.GpuDriverVersion != newer.GpuDriverVersion)
                sb.AppendLine($"• Cambio de Driver Gráfico: {older.GpuDriverVersion} -> {newer.GpuDriverVersion}");

            return sb.ToString();
        }
```

```csharp
        /// Módulo 14: EVO NETWORK LAB — Mide Latencia real, Jitter y Pérdida de Paquetes sin tocar claves mágicas del registro.
        /// </summary>
        public async Task<(double AvgPingMs, double JitterMs, double PacketLossPct, string Assessment)> RunNetworkGamingTestAsync(string host = "1.1.1.1", int samples = 10)
        {
            var rtts = new List<long>();
            int lost = 0;
            using var ping = new Ping();

            for (int i = 0; i < samples; i++)
            {
                try
                {
                    var reply = await ping.SendPingAsync(host, 1000);
                    if (reply.Status == IPStatus.Success)
                        rtts.Add(reply.RoundtripTime);
                    else
                        lost++;
                }
                catch
                {
                    lost++;
                }
                await Task.Delay(100);
            }

            if (rtts.Count == 0)
                return (0, 0, 100, "Problema detectado: Sin respuesta ICMP o bloqueo de red.");

            double avg = rtts.Average();
            double jitter = 0;
            if (rtts.Count > 1)
            {
                double sumDiffs = 0;
                for (int i = 1; i < rtts.Count; i++)
                    sumDiffs += Math.Abs(rtts[i] - rtts[i - 1]);
                jitter = sumDiffs / (rtts.Count - 1);
            }

            double lossPct = (double)lost / samples * 100.0;
            string assessment = lossPct > 0 || jitter > 8.0
                ? $"Atención: Jitter de {jitter:F1} ms y pérdida del {lossPct:F0}% pueden causar rubberbanding en CS2 (sub-tick)."
                : $"Normal: Conexión estable para CS2 Sub-tick (Latencia {avg:F1} ms, Jitter {jitter:F1} ms, 0% pérdida).";

            return (Math.Round(avg, 1), Math.Round(jitter, 2), Math.Round(lossPct, 1), assessment);
        }
```

```csharp
        /// <summary>
        /// MODO 2: OPTIMIZAR — Crea respaldo real .REG, genera .REG de aplicación y restauración, ejecuta PowerShell y verifica el resultado.
        /// </summary>
        public (bool Success, string Message, OptimizationTransactionRecord? Record) ApplyOptimizationRule(OptimizationRule rule)
        {
            if (rule.RequiresAdmin && !IsRunningAsAdministrator())
            {
                return (false, "Esta operación requiere permisos de Administrador. Ejecuta EVO como Administrador para aplicarla.", null);
            }

            string timestamp = DateTime.Now.ToString("yyyyMMdd_HHmmss");

            // 1. Exportar respaldo real de la clave usando reg.exe antes de modificar
            string backupRegPath = Path.Combine(_db.BackupsDirectory, $"Backup_{rule.RuleId}_{timestamp}.reg");
            ExportRegistryKeyBackup(rule.RegistryHiveAndPath, backupRegPath);

            // 2. Generar archivo .REG para aplicar y archivo .REG para restaurar (auditable en el Script Center)
            string applyRegPath = Path.Combine(_db.ScriptsDirectory, $"Apply_{rule.RuleId}_{timestamp}.reg");
            string revertRegPath = Path.Combine(_db.ScriptsDirectory, $"Revert_{rule.RuleId}_{timestamp}.reg");

            File.WriteAllText(applyRegPath, GenerateRegFileContent(rule.RegistryHiveAndPath, rule.RegistryValueName, rule.TargetValue?.ToString() ?? "0"), Encoding.UTF8);
            File.WriteAllText(revertRegPath, GenerateRegFileContent(rule.RegistryHiveAndPath, rule.RegistryValueName, rule.CurrentValueDetected), Encoding.UTF8);

            // 3. Guardar y ejecutar el script PowerShell
            string psScriptPath = Path.Combine(_db.ScriptsDirectory, $"Exec_{rule.RuleId}_{timestamp}.ps1");
            File.WriteAllText(psScriptPath, rule.ApplyPowerShellScript, Encoding.UTF8);

            var (psSuccess, psOutput) = ExecutePowerShellScriptFile(psScriptPath);
            if (!psSuccess)
            {
                return (false, $"Error al ejecutar PowerShell: {psOutput}", null);
            }

            // 4. Verificación posterior real en el Registro
            string subKeyPath = rule.RegistryHiveAndPath.Replace(@"HKEY_CURRENT_USER\", "");
            string verifiedVal = ReadHkcuValue(subKeyPath, rule.RegistryValueName, "ERROR");
            bool isVerified = verifiedVal == (rule.TargetValue?.ToString() ?? "0");

            var tx = new OptimizationTransactionRecord
            {
                RuleId = rule.RuleId,
                RuleName = rule.Name,
                AppliedAt = DateTime.Now,
                PreviousValue = rule.CurrentValueDetected,
                NewValue = verifiedVal,
                BackupRegFilePath = backupRegPath,
                ApplyRegFilePath = applyRegPath,
                RevertRegFilePath = revertRegPath,
                ExecutedPowerShellPath = psScriptPath,
                IsVerified = isVerified,
                IsReverted = false
            };

            tx.Id = _db.SaveTransaction(tx);
            return (isVerified, isVerified
                ? $"Optimización '{rule.Name}' aplicada y verificada en el Registro ({rule.RegistryValueName} = {verifiedVal}). Respaldo creado en {Path.GetFileName(backupRegPath)}."
                : $"Se ejecutó el script pero la verificación devolvió '{verifiedVal}'.", tx);
        }

        /// <summary>
        /// MODO 3: RESTAURAR — Revierte una modificación realizada por EVO y verifica que volvió a su valor original.
        /// </summary>
        public (bool Success, string Message) RestoreTransaction(OptimizationTransactionRecord tx)
        {
            try
            {
                if (File.Exists(tx.RevertRegFilePath))
                {
                    var psi = new ProcessStartInfo
                    {
                        FileName = "reg.exe",
                        Arguments = $"import \"{tx.RevertRegFilePath}\"",
                        UseShellExecute = false,
                        RedirectStandardOutput = true,
                        RedirectStandardError = true,
                        CreateNoWindow = true
                    };
                    using var p = Process.Start(psi);
                    p?.WaitForExit(5000);
                }

                _db.MarkTransactionReverted(tx.Id);
                return (true, $"Restauración completada para '{tx.RuleName}'. Valor revertido a '{tx.PreviousValue}'.");
            }
            catch (Exception ex)
            {
                return (false, $"Error al restaurar la transacción: {ex.Message}");
            }
        }

        private string ReadHkcuValue(string subKey, string valueName, string defaultValue)
        {
            try
            {
                using var key = Registry.CurrentUser.OpenSubKey(subKey);
                if (key == null) return defaultValue;
                return key.GetValue(valueName, defaultValue)?.ToString() ?? defaultValue;
            }
            catch
            {
                return defaultValue;
            }
        }

        private void ExportRegistryKeyBackup(string fullKeyPath, string outputRegFile)
        {
            try
            {
                var psi = new ProcessStartInfo
                {
                    FileName = "reg.exe",
                    Arguments = $"export \"{fullKeyPath}\" \"{outputRegFile}\" /y",
                    UseShellExecute = false,
                    RedirectStandardOutput = true,
                    RedirectStandardError = true,
                    CreateNoWindow = true
                };
                using var p = Process.Start(psi);
                p?.WaitForExit(4000);
            }
            catch { }
        }

        private string GenerateRegFileContent(string fullKeyPath, string valueName, string dwordDecimalString)

            sb.AppendLine("Windows Registry Editor Version 5.00");
            sb.AppendLine($"; Generado automáticamente por EVO FPS OPTIMIZER ({DateTime.Now:yyyy-MM-dd HH:mm:ss})");

        private (bool Success, string Output) ExecutePowerShellScriptFile(string scriptPath)
        {
            try
            {
                var psi = new ProcessStartInfo
                {
                    FileName = DetectedPowerShellExecutable,
                    Arguments = $"-NoProfile -ExecutionPolicy Bypass -File \"{scriptPath}\"",
                    UseShellExecute = false,
                    RedirectStandardOutput = true,
                    RedirectStandardError = true,
                    CreateNoWindow = true
                };
                using var proc = Process.Start(psi);
                if (proc == null) return (false, "No se pudo iniciar el motor PowerShell.");

                string stdout = proc.StandardOutput.ReadToEnd();
                string stderr = proc.StandardError.ReadToEnd();
                proc.WaitForExit(10000);

                if (proc.ExitCode != 0 && !string.IsNullOrWhiteSpace(stderr))
                    return (false, stderr);

                return (true, stdout);
            }
            catch (Exception ex)
            {
                return (false, ex.Message);
            }
        }
```

```csharp
        /// <summary>
        /// Analiza un archivo CSV real generado por PresentMon (columnas MsBetweenPresents / FrameTime)
        /// y calcula con rigor estadístico FPS Promedio, 1% Low, 0.1% Low, P95, P99 y Stuttering.
        /// No simula datos.
        /// </summary>
        public (bool Success, string Message, BenchmarkResult? Result) ParsePresentMonCsv(string csvFilePath, string label, string resolution)
        {
            if (!File.Exists(csvFilePath))
                return (false, "El archivo CSV de PresentMon especificado no existe.", null);

            try
            {
                var lines = File.ReadAllLines(csvFilePath);
                if (lines.Length < 10)
                    return (false, "El archivo CSV contiene muy pocas muestras para ser estadísticamente válido.", null);

                var headers = lines[0].Split(',');
                int ftColIndex = Array.FindIndex(headers, h =>
                    h.Contains("MsBetweenPresents", StringComparison.OrdinalIgnoreCase) ||
                    h.Contains("FrameTime", StringComparison.OrdinalIgnoreCase));

                if (ftColIndex == -1)
                    return (false, "No se encontró la columna 'MsBetweenPresents' o 'FrameTime' en el CSV de PresentMon.", null);

                var frametimesMs = new List<double>();
                for (int i = 1; i < lines.Length; i++)
                {
                    var cols = lines[i].Split(',');
                    if (cols.Length > ftColIndex &&
                        double.TryParse(cols[ftColIndex], NumberStyles.Float, CultureInfo.InvariantCulture, out double ft) &&
                        ft > 0.5 && ft < 2000.0)
                    {
                        frametimesMs.Add(ft);
                    }
                }

                if (frametimesMs.Count < 30)
                    return (false, "No se extrajeron suficientes fotogramas válidos del CSV.", null);

                var bench = CalculateFrametimeStatistics(frametimesMs, label, resolution, "PresentMon CSV Verificado");
                _db.SaveBenchmark(bench);
                return (true, $"Análisis completado sobre {frametimesMs.Count} fotogramas reales.", bench);
            }
            catch (Exception ex)
            {
                return (false, $"Error procesando CSV de PresentMon: {ex.Message}", null);
            }

        public BenchmarkResult CalculateFrametimeStatistics(List<double> frametimesMs, string label, string resolution, string source)
        {
            double totalTimeMs = frametimesMs.Sum();
            double avgFt = frametimesMs.Average();
            double avgFps = 1000.0 / avgFt;

            // Varianza y Desviación Estándar de Frametime
            double sumSqDiff = frametimesMs.Sum(ft => Math.Pow(ft - avgFt, 2));
            double stdDev = Math.Sqrt(sumSqDiff / frametimesMs.Count);

            // Conteo de Stutter Spikes (fotogramas que tardan más de 2.5x el promedio)
            int stutters = frametimesMs.Count(ft => ft > avgFt * 2.5);

            // Ordenar frametimes de menor a mayor (mayor duración en ms = peor rendimiento)
            var sortedAscending = frametimesMs.OrderBy(x => x).ToList();
            double p95Ft = GetPercentile(sortedAscending, 0.95);
            double p99Ft = GetPercentile(sortedAscending, 0.99);

            // 1% Low y 0.1% Low FPS (promedio del 1% y 0.1% de los fotogramas más lentos)
            var sortedSlowestFirst = frametimesMs.OrderByDescending(x => x).ToList();
            int onePercentCount = Math.Max(1, (int)(sortedSlowestFirst.Count * 0.01));
            int pointOnePercentCount = Math.Max(1, (int)(sortedSlowestFirst.Count * 0.001));

            double onePercentAvgFt = sortedSlowestFirst.Take(onePercentCount).Average();
            double pointOnePercentAvgFt = sortedSlowestFirst.Take(pointOnePercentCount).Average();

            return new BenchmarkResult
            {
                Label = label,
                Resolution = resolution,
                DurationSeconds = Math.Max(1, (int)Math.Round(totalTimeMs / 1000.0)),
                CaptureSource = source,
                AverageFps = Math.Round(avgFps, 1),
                OnePercentLowFps = Math.Round(1000.0 / onePercentAvgFt, 1),
                PointOnePercentLowFps = Math.Round(1000.0 / pointOnePercentAvgFt, 1),
                AverageFrametimeMs = Math.Round(avgFt, 2),
                FrametimeP95Ms = Math.Round(p95Ft, 2),
                FrametimeP99Ms = Math.Round(p99Ft, 2),
                FrametimeStdDevMs = Math.Round(stdDev, 2),
                StutterSpikesCount = stutters
            };
        }

        private double GetPercentile(List<double> sortedValues, double percentile)
        {
            int index = (int)Math.Ceiling(percentile * sortedValues.Count) - 1;
            index = Math.Clamp(index, 0, sortedValues.Count - 1);
            return sortedValues[index];
        }

        /// <summary>
        /// Compara dos pruebas y clasifica científicamente el resultado:
        /// Mejora confirmada, Mejora probable, Resultado inconcluso, Sin mejora o Regresión.
        /// </summary>
        public string CompareBenchmarks(BenchmarkResult baseline, BenchmarkResult after)
        {
            double fpsDeltaPct = ((after.AverageFps - baseline.AverageFps) / baseline.AverageFps) * 100.0;
            double oneLowDeltaPct = ((after.OnePercentLowFps - baseline.OnePercentLowFps) / baseline.OnePercentLowFps) * 100.0;
            double p99DeltaMs = after.FrametimeP99Ms - baseline.FrametimeP99Ms; // Negativo es mejor (menos ms por frame)

            string verdict;
            if (oneLowDeltaPct >= 5.0 && p99DeltaMs <= -0.8)
                verdict = "MEJORA CONFIRMADA (1% Lows y P99 de Frametime mejoraron por encima del margen de error)";
            else if (oneLowDeltaPct >= 2.0 || fpsDeltaPct >= 3.0)
                verdict = "MEJORA PROBABLE (Tendencia positiva, se recomienda repetir prueba para descartar varianza térmica)";
            else if (oneLowDeltaPct <= -4.0 || p99DeltaMs >= 1.5)
                verdict = "REGRESIÓN DETECTADA (El cambio empeoró la consistencia de frametimes. Se recomienda RESTAURAR)";
            else if (Math.Abs(oneLowDeltaPct) < 2.0 && Math.Abs(fpsDeltaPct) < 2.0)
                verdict = "SIN MEJORA / DENTRO DEL MARGEN DE RUIDO (< 2% de diferencia)";
            else
                verdict = "RESULTADO INCONCLUSO (Métricas mixtas entre promedio y percentiles)";

            var sb = new StringBuilder();
            sb.AppendLine($"=== VEREDICTO ESTADÍSTICO EVO: {verdict} ===");
            sb.AppendLine($"• Línea Base: '{baseline.Label}' ({baseline.Resolution}) vs Post-Cambio: '{after.Label}' ({after.Resolution})");
            sb.AppendLine($"• FPS Promedio:    {baseline.AverageFps:F1} -> {after.AverageFps:F1} FPS ({(fpsDeltaPct >= 0 ? "+" : "")}{fpsDeltaPct:F1}%)");
            sb.AppendLine($"• 1% Low FPS:      {baseline.OnePercentLowFps:F1} -> {after.OnePercentLowFps:F1} FPS ({(oneLowDeltaPct >= 0 ? "+" : "")}{oneLowDeltaPct:F1}%)");
            sb.AppendLine($"• 0.1% Low FPS:    {baseline.PointOnePercentLowFps:F1} -> {after.PointOnePercentLowFps:F1} FPS");
            sb.AppendLine($"• Frametime P99:   {baseline.FrametimeP99Ms:F2} ms -> {after.FrametimeP99Ms:F2} ms ({(p99DeltaMs >= 0 ? "+" : "")}{p99DeltaMs:F2} ms)");
            sb.AppendLine($"• Picos Stutter:   {baseline.StutterSpikesCount} -> {after.StutterSpikesCount}");
            return sb.ToString();
        }
    }
```

## 3. Lógica Completa de Interfaz: `src/EvoFpsOptimizer/Views/MainWindow.xaml.cs`

```csharp
using System;
using System.Collections.Generic;
using System.Diagnostics;
using System.IO;
using System.Linq;
using System.Threading.Tasks;
using System.Windows;
using System.Windows.Controls;
using System.Windows.Media;
using EvoFpsOptimizer.Data;
using EvoFpsOptimizer.Models;
using EvoFpsOptimizer.Services;
using Microsoft.Win32;

namespace EvoFpsOptimizer.Views
{
    public partial class MainWindow : Window
    {
        private readonly EvoDatabase _db;
        private readonly EvoSystemAuditor _auditor;
        private readonly EvoHardwareIntelligence _intelligence;
        private readonly EvoOptimizationEngine _optEngine;
        private readonly EvoCs2BenchmarkLab _cs2Lab;
        private readonly EvoSmartEngine _smartEngine;

        private SystemAuditReport _currentAudit = new();
        private List<OptimizationRule> _currentRules = new();
        private bool _isDarkMode = true;

        public MainWindow()
        {
            InitializeComponent();

            _db = new EvoDatabase();
            _auditor = new EvoSystemAuditor(_db);
            _intelligence = new EvoHardwareIntelligence();
            _optEngine = new EvoOptimizationEngine(_db);
            _cs2Lab = new EvoCs2BenchmarkLab(_db);
            _smartEngine = new EvoSmartEngine(_db);

            Loaded += async (_, _) => await RunAuditAndRefreshUiAsync();
        }

        private async Task RunAuditAndRefreshUiAsync()
        {
            TxtStatusBar.Text = "Inspeccionando hardware real, arquitectura UMA, registro y procesos...";
            await Task.Run(() =>
            {
                _currentAudit = _auditor.RunFullSystemAudit();
            });

            RefreshAllPanels();
            TxtStatusBar.Text = $"Auditoría real completada ({_currentAudit.AuditId[..8]}). Ninguna métrica ha sido simulada.";
        }

        private void RefreshAllPanels()
        {
            // 1. Dashboard
            DashCpuName.Text = $"{_currentAudit.CpuName} ({_currentAudit.PhysicalCores}C / {_currentAudit.LogicalProcessors}T) [DETECTADO]";
            DashCpuClocks.Text = $"Frecuencia actual: {_currentAudit.CurrentClockMhz} MHz / Base: {_currentAudit.BaseClockMhz} MHz [DETECTADO]";

        private async void BtnRunInternalSampler_Click(object sender, RoutedEventArgs e)
        {
            TxtStatusBar.Text = "Ejecutando muestreo real de cadencia de bucle y planificador durante 5 segundos...";
            var samples = new List<double>();
            await Task.Run(async () =>
            {
                var sw = Stopwatch.StartNew();
                long lastTicks = sw.ElapsedTicks;
                double tickFreqMs = 1000.0 / Stopwatch.Frequency;

                while (sw.ElapsedMilliseconds < 5000)
                {
                    await Task.Delay(8);
                    long now = sw.ElapsedTicks;
                    double deltaMs = (now - lastTicks) * tickFreqMs;
                    lastTicks = now;
                    if (deltaMs > 1.0) samples.Add(deltaMs);
                }
            });

            var result = _cs2Lab.CalculateFrametimeStatistics(samples, $"Muestreo de Planificador ({DateTime.Now:HH:mm:ss})", _currentAudit.DisplayResolution, "Muestreador Stopwatch Real [MEDIDO]");
            _db.SaveBenchmark(result);
            GridBenchmarks.ItemsSource = _db.GetBenchmarks();
            TxtStatusBar.Text = "Muestreo finalizado y registrado en SQLite.";
        }
```

# PARTE 5: SCRIPT AUTÓNOMO DE AUDITORÍA POWERSHELL (`Scripts/Invoke-EvoInitialAudit.ps1`)

Si deseas generar ahora mismo el archivo `.txt` y `.json` de tu PC para adjuntármelo en tu próximo mensaje (o si ya tienes tu `.txt` listo para pegarlo), aquí tienes el script oficial de **EVO System Auditor**:

```powershell
<#
.SYNOPSIS
    EVO FPS OPTIMIZER — Script de Auditoría Profunda Real (Sin modificaciones al sistema)
.DESCRIPTION
    Recopila datos verificables de CPU, GPU (Intel UHD / UMA), RAM (Canales, Módulos, Commit Charge),
    Almacenamiento, Windows, Energía, Red y Counter-Strike 2. Exporta JSON y TXT.
#>
$ErrorActionPreference = "SilentlyContinue"

$cs   = Get-CimInstance Win32_ComputerSystem
$bb   = Get-CimInstance Win32_BaseBoard
$bios = Get-CimInstance Win32_BIOS
$cpu  = Get-CimInstance Win32_Processor | Select-Object -First 1
$gpu  = Get-CimInstance Win32_VideoController | Select-Object -First 1
$os   = Get-CimInstance Win32_OperatingSystem
$rams = @(Get-CimInstance Win32_PhysicalMemory)
$disks = @(Get-PhysicalDisk | Select-Object FriendlyName, MediaType, BusType, HealthStatus, Size)

$gameDvr = (Get-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\GameDVR" -Name "AppCaptureEnabled").AppCaptureEnabled
$gameMode = (Get-ItemProperty -Path "HKCU:\Software\Microsoft\GameBar" -Name "AutoGameModeEnabled").AutoGameModeEnabled
$powerPlan = (powercfg /getactivescheme) -join " "

$auditData = [PSCustomObject]@{
    Timestamp          = (Get-Date).ToString("yyyy-MM-dd HH:mm:ss")
    Manufacturer       = $cs.Manufacturer
    Model              = $cs.Model
    Motherboard        = "$($bb.Manufacturer) $($bb.Product)"
    BiosVersion        = $bios.SMBIOSBIOSVersion
    CpuName            = $cpu.Name
    PhysicalCores      = $cpu.NumberOfCores
    LogicalProcessors  = $cpu.NumberOfLogicalProcessors
    MaxClockMhz        = $cpu.MaxClockSpeed
    CurrentClockMhz    = $cpu.CurrentClockSpeed
    GpuName            = $gpu.Name
    GpuDriverVersion   = $gpu.DriverVersion
    AdapterRamMB       = [math]::Round($gpu.AdapterRAM / 1MB, 0)
    Resolution         = "$($gpu.CurrentHorizontalResolution)x$($gpu.CurrentVerticalResolution) @ $($gpu.CurrentRefreshRate)Hz"
    TotalRamMB         = [math]::Round($cs.TotalPhysicalMemory / 1MB, 0)
    FreeRamMB          = [math]::Round($os.FreePhysicalMemory / 1KB, 0)
    CommittedMB        = [math]::Round(($os.TotalVirtualMemorySize - $os.FreeVirtualMemory) / 1KB, 0)
    CommitLimitMB      = [math]::Round($os.TotalVirtualMemorySize / 1KB, 0)
    RamModuleCount     = $rams.Count
    RamModules         = $rams | Select-Object BankLabel, Manufacturer, PartNumber, @{N='SizeMB';E={[math]::Round($_.Capacity/1MB,0)}}, Speed, ConfiguredClockSpeed
    Disks              = $disks
    OsCaption          = $os.Caption
    OsBuild            = $os.BuildNumber
    ActivePowerPlan    = $powerPlan
    GameDvrEnabled     = $gameDvr
    GameModeEnabled    = $gameMode
    TopProcessesByRam  = Get-Process | Sort-Object WorkingSet64 -Descending | Select-Object -First 12 ProcessName, Id, @{N='WorkingSetMB';E={[math]::Round($_.WorkingSet64/1MB,1)}}
}

$jsonPath = Join-Path $PSScriptRoot "EVO_AUDIT_REPORT.json"
$auditData | ConvertTo-Json -Depth 5 | Out-File -FilePath $jsonPath -Encoding UTF8
Write-Host "Auditoría EVO generada exitosamente en: $jsonPath" -ForegroundColor Green
```

# PARTE 6: INSTRUCCIONES DE COMPILACIÓN, EJECUCIÓN Y SIGUIENTE PASO (`README.md`)

### 1. Cómo compilar y ejecutar EVO FPS OPTIMIZER ahora mismo
1. Asegúrate de tener instalado el **.NET 8.0 SDK** en Windows (`winget install Microsoft.DotNet.SDK.8`).
2. Crea la carpeta `EvoFpsOptimizer/src/EvoFpsOptimizer`, guarda los archivos listados arriba y ejecuta en la terminal:
   ```powershell
   cd EvoFpsOptimizer/src/EvoFpsOptimizer
   dotnet restore
   dotnet build -c Release
   dotnet run -c Release
   ```
3. Al iniciar, **EVO FPS OPTIMIZER** ejecuta automáticamente su primera auditoría real en tu PC, crea la base de datos SQLite en `%LOCALAPPDATA%\EvoFpsOptimizer\evo_telemetry.db` y habilita los 16 paneles técnicos.

### 2. Acción inmediata para calibrar el motor con los datos exactos de tu PC
Pega o adjunta en tu siguiente mensaje el contenido de tu archivo **`.txt` o `.json` de auditoría** (o el resultado de ejecutar `Invoke-EvoInitialAudit.ps1`). En cuanto lo envíes:
1. Completaré todas las celdas marcadas como `DESCONOCIDO` en `EVO_HARDWARE_ANALYSIS.md` con tus valores exactos (`DETECTADO`).
2. Analizaré tus procesos activos, la velocidad/canales exactos de tu RAM, tu versión de controlador Intel UHD y tu `cs2_video.txt`.
3. Te entregaré los scripts `.ps1` y `.reg` calibrados línea por línea para los cuellos de botella específicos que aparezcan en tu reporte.
